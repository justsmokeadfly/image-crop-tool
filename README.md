# 🖼️ Обработчик изображений v1.9

Простой веб-инструмент на **Streamlit** для пакетной обработки изображений.

Приложение автоматически или вручную обрезает изображения, помещает их на квадратный холст с заданным отступом и при необходимости конвертирует результат в PNG или JPG.

## ✨ Возможности

- 📁 Загрузка нескольких изображений одновременно
- ✂️ Автоматическая обрезка пустых полей
- 🎯 Ручная обрезка по четырём сторонам
- ⬜ Режим без обрезки
- 📐 Настройка размера квадратного холста
- ↔️ Настройка отступа
- 🖼️ Экспорт в PNG или JPG
- 🔲 Прозрачный фон для PNG
- 📦 Скачивание всех результатов одним ZIP-архивом
- 🗑️ Удаление отдельных файлов из списка
- ☀️ Светлая и 🌙 тёмная тема
- 🚀 Работа прямо в браузере через Streamlit Community Cloud
- 🧩 Поддержка AVIF при наличии `pillow-avif-plugin`

## 🛡️ Что нового в v1.9

## 🚀 Запуск локально

### 1. Клонирование репозитория

```bash
git clone https://github.com/justsmokeadfly/image-crop-tool.git
cd image-crop-tool
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Запуск

```bash
streamlit run app.py
```

После запуска Streamlit откроет приложение в браузере.

## 🧪 Запуск тестов

Для разработки установите дополнительные зависимости:

```bash
pip install -r requirements-dev.txt
```

Затем:

```bash
pytest -q
```

## ☁️ Streamlit Community Cloud

Проект рассчитан на запуск через **Streamlit Community Cloud**.

В настройках приложения укажите:

- **Repository:** `justsmokeadfly/image-crop-tool`
- **Branch:** `main`
- **Main file:** `app.py`

Зависимости устанавливаются автоматически из `requirements.txt`.

В v1.9 размер одного загружаемого файла ограничен 50 МБ настройкой Streamlit.

## 🛠️ Технологии

- Python
- Streamlit
- Pillow
- pillow-avif-plugin
- pytest — для тестирования

## 📄 Поддерживаемые форматы

**Вход:** PNG, JPG, JPEG, WEBP, BMP, TIFF, GIF и AVIF.

**Выход:** PNG или JPG.

## 📌 Как пользоваться

1. Загрузите одно или несколько изображений.
2. Выберите параметры обработки в боковой панели.
3. Выберите режим обрезки: автоматический, ручной или без обрезки.
4. Нажмите **«Обработать изображения»**.
5. Скачайте готовые файлы по отдельности или одним ZIP-архивом.
